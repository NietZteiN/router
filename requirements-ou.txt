# open-unlearning evaluation environment — the SECOND env, curated from the cluster's
# `unlearning` conda env (Python 3.11).
#
#     conda create -n unlearning python=3.11 && conda activate unlearning
#     pip install -r requirements-ou.txt
#     bash fetch_upstream.sh && cd open-unlearning && pip install -e .
#
# WHY A SECOND ENV. This is NOT requirements.txt with different numbers — the two are mutually
# exclusive. The main tree pins transformers 4.48.3 / torch 2.5.1; open-unlearning needs
# transformers 4.51.3 / torch 2.4.1, and the two majors resolve the Llama-3.2 chat template
# differently, so a metric computed under the wrong one is silently off rather than an error.
# `cluster_env.sh` exposes both as $TOFU_PYTHON and $TOFU_OU_PYTHON; every driver that runs an
# OU eval uses the latter.
#
# Which tracks need it: the OU/chat-template arms of sepmlp_tofu, blocktc_tofu and memadapt_tofu
# (the Table-1 `Agg`/`Priv` numbers). Everything else — the whole routing and merging tree —
# runs under requirements.txt alone.
#
# torch here is the plain CUDA wheel; install the build matching your driver if it differs
# (https://pytorch.org).
