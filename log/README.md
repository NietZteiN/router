# Experiment Log

Chronological research ledger for exact / near-exact machine unlearning in LLMs.
Maintained per [CLAUDE.md](../CLAUDE.md) §6: **one dated entry per working day per
experiment thread, append-only** (never alter a historical entry — corrections go in a
new dated entry). Each entry follows a full scientific-method loop:
*Hypotheses → Setup → Results → What worked/verdict → Observations → New questions/hypotheses
→ Next Steps*. A blank copy of this template (and the thread-README skeleton) lives in
[`TEMPLATE.md`](TEMPLATE.md).

This folder replaces the old flat `LOG.md`: entries are split **by experiment** (one
folder per thread) and **by date** (`YYYY-MM-DD_<slug>.md` inside each thread). Each
thread folder has a `README.md` summarizing status, hypotheses (open/resolved), what
worked, what didn't, and open ideas. This file is the master index.
